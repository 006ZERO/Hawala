# Security policy

## Supported version

Security fixes are applied to the latest commit on `main`. This repository is a demonstration and must not be used for real customer data, sanctions decisions, regulatory filings, or funds movement.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not disclose suspected vulnerabilities in a public issue.

Include the affected component, reproduction steps, impact, and any suggested mitigation. Do not include real personal, financial, identity, or authentication data in a report.

## Demonstration boundaries

The screening integration uses synthetic fixtures. Identity, payment, safeguarding, and regulatory connections are not included. A production deployment requires buyer-controlled identity, secrets management, monitoring, independent penetration testing, and regulatory approval.
